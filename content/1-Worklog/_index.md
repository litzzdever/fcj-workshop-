This worklog records my internship in the **AWS First Cloud AI Journey (FCAJ)** program, which ran for **12 weeks, from 14/09/2026 to 14/12/2026**.

**How I worked:** Each week I set goals, studied AWS Study Group workshops and official tutorials in the AWS Documentation, practiced hands-on in an AWS account, and logged each day's tasks, references, errors, and fixes. After every lab I cleaned up resources to avoid charges. Alongside my studies, I worked on the team project **Phu Tung Xe May Platform**, where I was responsible for the RAG chatbot.

**12-week roadmap:**

- **Weeks 1–2:** AWS fundamentals and Amazon EC2
- **Weeks 3–7:** data, serverless, AI/ML, and building the project chatbot
- **Week 8:** containers with Amazon EKS and deep learning infrastructure
- **Weeks 9–10:** workflow orchestration, streaming data, and analytics
- **Week 11:** AWS ready-made AI services
- **Week 12:** CI/CD, security, governance, and final review

**Weekly content:**

**Week 1:** [Getting familiar with the AWS Management Console, AWS accounts, and Amazon EC2](1.1-week1/)

**Week 2:** [EC2 administration on Windows and Linux, EBS snapshots, custom AMIs, deploying a web app, and IAM cost controls](1.2-week2/)

**Week 3:** [A RAG data pipeline on AWS: S3, embeddings, OpenSearch Serverless, and Amazon Bedrock](1.3-week3/)

**Week 4:** [Amazon DynamoDB, AWS CLI, Lambda with EventBridge, Secrets Manager with RDS and Fargate, CloudWatch](1.4-week4/)

**Week 6:** [Improving the project's RAG chatbot: WebSocket, cold start measurement, testing, and documentation](1.6-week6/)

**Week 7:** [AWS AppSync: GraphQL APIs with DynamoDB, resolvers, and authorization](1.7-week7/)

**Week 8:** [Amazon EKS (Auto Mode and a hand-built cluster) and AWS Deep Learning AMIs](1.8-week8/)

**Week 9:** [AWS Step Functions, Kinesis Data Streams, Data Firehose, and Amazon Athena](1.9-week9/)

**Week 12:** [CodeBuild, CodePipeline, KMS, WAF, Config, Security Hub CSPM, Organizations, and final review](1.12-week12/)
